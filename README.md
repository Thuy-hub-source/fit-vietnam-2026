# e-Sia Learning · FIT Vietnam 2026

Bilingual (English / Tiếng Việt) microsite for the FIT Vietnam trade mission, October 2026.

**Live:** [thuy-hub-source.github.io/fit-vietnam-2026](https://thuy-hub-source.github.io/fit-vietnam-2026/)

## Features

- 🌐 **Bilingual EN / VI** — toggle with the language pill top-right, or with `?lang=en` / `?lang=vi`
- 🎬 **Built-in presenter mode** — press `P` to enter, arrow keys / space to navigate, `Esc` to exit. Or land directly in it with `?present=1`
- 📄 **Downloadable materials** — the full deck and four segment-specific one-pagers are attached in the *Documents* section, ready to hand over on-site
